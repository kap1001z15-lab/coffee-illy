# Coffee Illy v90.0 (Minimalist M3 Soft · Production Release)

## Что нового в v90.0
- **Быстрая и бесшовная синхронизация между устройствами:** настраиваемая скорость `SYNC_MODE` (`realtime` 0.8с / `balanced` 2с / `economy` 6с), мгновенный `BroadcastChannel`-мост между вкладками и живой индикатор `● Live` в шапке с ручным форс-обновлением по клику.
- **Детальное управление настройками:** сгруппированный раздел настроек с гибридными выпадающими списками (`SYNC_MODE`, `THEME_DEFAULT`, `CURRENCY`, `PIN_POLICY`, `TG_ALERTS_MODE`, `PHOTO_ALL`), временными окнами и числовыми полями с серверной валидацией границ в `Code.gs`.
- **Минималистичный интерфейс:** единый слой `css/v90-minimal.css` с автоматическим переключением светлой/тёмной темы ОС и Telegram.

## Установка без потери данных (3 шага)
1. **Apps Script:** замените `Code.gs` кодом из `Coffee_Illy_Code_v90.0.gs.txt` и обновите текущее развертывание (*Управление развертываниями → Редактировать → Новая версия*).
2. **GitHub Pages:** распакуйте `coffee-illy-v90.0-release.zip` в корень репозитория и сделайте `git push`.
3. **Проверка:** откройте `owner.html` (дашборд владельца) и `index.html` (терминал бариста / Telegram Mini App).
