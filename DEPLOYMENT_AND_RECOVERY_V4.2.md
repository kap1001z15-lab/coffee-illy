# Инструкция по установке, обновлению, резервированию и откату Coffee Illy v4.2

## 1. Резервное копирование перед обновлением (обязательно)
1. В Google Drive создайте копию рабочей Google Таблицы (Файл → Создать копию).
2. Создайте резервную копию папки `Coffee_ERP_Photos` (или зафиксируйте её ID).
3. В Google Apps Script зафиксируйте номер текущего стабильного Deployment (v86).
4. Сохраните JSON-экспорт настроек из текущей панели администратора (Настройки → Экспорт резервной копии).

## 2. Установка и обновление Backend (Google Apps Script)
1. Сначала протестируйте на **staging-копии** таблицы.
2. Замените содержимое `Code.gs` в редакторе Apps Script на обновлённый `Code.gs` из сборки v4.2.
3. Выполните `setupAndVerifyCoffeeServer()` и убедитесь в отсутствии ошибок.
4. При первичной настройке вызовите `setup_initial_credentials` (или задайте 6-значные PIN через панель администратора).
5. Опубликуйте новую версию Web App (Развёртывание → Новое развёртывание).

## 3. Обновление Frontend (GitHub Pages / статический хостинг)
1. Распакуйте архив `coffee-illy-v4.2-complete.zip` в корень репозитория `kap1001z15-lab/coffee-illy`.
2. Убедитесь, что `config.js` указывает на актуальный URL развёрнутого Web App.
3. После публикации Service Worker `kofeinya-enterprise-v87` автоматически очистит старый кэш.

## 4. Восстановление из резервной копии и план отката
1. **Откат кода:** в Google Apps Script переключите активное развёртывание на предыдущую версию (v86); на GitHub Pages выполните `git revert` к предыдущему коммиту. Структура листов Google Таблицы полностью обратно совместима (добавлены только новые опциональные листы `ПередачаСмен`, `Списания`, `Корректировки`).
2. **Восстановление данных:** при повреждении листа восстановите данные из созданной копии Google Таблицы или JSON-резервной копии в новую тестовую копию, сверьте записи и переключите `SpreadsheetApp`.
