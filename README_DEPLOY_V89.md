# Coffee Illy v89.0 (Material 3 Soft · Production Release)

## Быстрое обновление без потери данных (3 шага)

1. **Google Apps Script (`Code.gs`):**
   - Откройте ваш проект Apps Script, привязанный к таблице `Coffee_illy` (`1FWFec1EvqeQ_2lnVIftyTgkeYfzIqFmmRWucpAaedqM`).
   - Замените содержимое `Code.gs` кодом из файла `Coffee_Illy_Code_v89.0.gs.txt` (или `Code.gs` из архива).
   - Нажмите **Развертывание → Управление развертываниями → Редактировать → Новая версия → Развернуть**.
   - **Важно:** не создавайте новую таблицу и не меняйте существующий `/exec`-адрес — все старые чек-листы, финансы, расходы, ТТК, сотрудники, PIN-коды и привязки Telegram ID подтянутся автоматически.

2. **Фронтенд (GitHub Pages / хостинг):**
   - Распакуйте содержимое `coffee-illy-v89.0-release.zip` в корень репозитория и сделайте `git push`.
   - При первом открытии Service Worker (`v89`) обновит кэш автоматически.

3. **Проверка после деплоя:**
   - Дашборд владельца: `owner.html` (управление параметрами, финансами, блоками, штатом, ТТК и безопасностью).
   - Терминал бариста / Telegram Mini App: `index.html` / `barista.html` (автотема ОС и Telegram, вход по личному PIN / Telegram ID).
