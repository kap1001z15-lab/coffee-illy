# Coffee Illy v94.0 (Minimalist Single-Window + Photo/15s Video Camera)

## Что нового в v94.0
1. **Живая камера: фото + видео до 15 секунд, без галереи и с 1 разрешением за смену**:
   - Запрос доступа к камере выполняется **1 раз при входе** (`CoffeeCameraV94.prewarm()`), поток остаётся тёплым на всю смену — повторных всплывающих запросов разрешения на следующих шагах нет.
   - В окне камеры доступны **📷 Фото** и **🎬 Видео (до 15с)** с таймером `REC 00:00 / 00:15` и авто-стопом на 15-й секунде. Загрузка из галереи полностью отключена.
   - И фото (JPEG), и видео (WebM/MP4) загружаются напрямую на Google Диск (`Coffee_ERP_Photos`) и записываются в лист `Медиафайлы`.
2. **Все правки интерфейса по результатам полевого теста**:
   - `Этапы смены / Показать все` → **`Таймлайн`** + аккуратная стрелка **`▾`**.
   - Описание/инструкция пункта открыто по умолчанию, кнопка **`▾`** без лишнего текста отцентрирована по экрану.
   - Убрано дублирование пунктов чек-листа (дедупликация и на сервере `Code.gs`, и на клиенте).
   - Добавлен отдельный финальный экран подтверждения **«Вы уверены, что хотите завершить чек-лист?»** — после завершения приложение больше не перескакивает само в следующий чек-лист.
   - Касса: кнопка **`CSV / XLS`** по центру, кнопка **`Сохранить`** вместо длинного текста.
   - Исправлена мобильная клавиатура: тап вне поля, `Enter` или кнопка **`Готово ⌄`** мгновенно убирают клавиатуру, нижнее меню при вводе скрывается.
   - Вкладка **База**: 4 категории (**Сделать на смене**, **Карта добрых дел**, **Рецептура**, **Прочее**), а строка поиска перенесена вниз под палец.
   - Вкладка `Поломки` → **`Задачи`**, кнопка `+ Сообщить о поломке` → **`+ Задача`**.

## Установка (2 шага)
1. **Google Apps Script**: обновите код содержимым `Coffee_Illy_Code_v94.0.gs.txt` → **Развернуть → Управление развёртываниями → Редактировать → Новая версия → Развернуть**.
2. **GitHub Pages**: распакуйте `coffee-illy-v94.0-m3soft-production.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и отправьте в Git:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v94.0: photo+15s video camera, single permission, minimalist UI"
   git push origin main
   ```
