# Coffee Illy v94.0 — Финальный кроссплатформенный продукт

Единая система управления кофейней (терминал бариста + дашборд владельца + Google Таблица + Google Диск + Telegram-бот), адаптированная для **Android, iOS, Windows и macOS** (PWA + Telegram Mini App).

## Что входит в релиз v94.0
- **Единый интерфейс Material 3 Soft**: светлая и тёмная темы (авто по системе или ручной переключатель), векторные SVG-иконки, защита от автозума полей на iOS, safe-area отступы под вырезы iPhone/Android, мгновенный отклик кнопок (`touch-action: manipulation`) и собственные иконки PWA для главного экрана.
- **Авто-вход сотрудника + приветствие + «На работе»**: автоматическое определение по Telegram ID или запомненному устройству, запись на лист `Посещаемость` и отображение статуса `На работе с ЧЧ:ММ` в дашборде владельца.
- **Камера → Google Диск**: съёмка в чек-листах и поломках, сжатие JPEG и сохранение в папку `Coffee_ERP_Photos` с кликабельными ссылками в таблице, дашборде и Telegram-уведомлениях.
- **Кросс-устройственная синхронизация**: 0.9–1.8 сек между разными устройствами (Android / iOS / Windows / Mac) через лёгкий опрос `get_rev` + офлайн-очередь с автоматической доотправкой и пробуждением iOS Safari (`pageshow` / `visibilitychange`).
- **Telegram-бот**: мгновенные алерты администратору при поломках (с фото и кнопкой дашборда) + автоматическая рассылка каждые 5 минут сотруднику на смене при открытии чек-листа с кнопкой прямого перехода (`index.html?block=...`).

## Установка за 3 шага
1. **Google Apps Script**: замените код в вашем проекте Apps Script на `Coffee_Illy_Code_v94.0.gs.txt`, сохраните и выберите **Развернуть → Управление развёртываниями → Редактировать → Новая версия → Развернуть**.
2. **GitHub Pages**: распакуйте `coffee-illy-v94.0-final-product.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v94.0 Final Product"
   git push origin main
   ```
3. **Настройка Telegram и установка как приложение**:
   - Откройте `owner.html` → **Настройки** → сохраните токен бота, Chat ID администратора и URL сайта, нажмите **Авто-уведомления (5 мин)** и **Тест админу**.
   - На iOS (Safari → Поделиться → На экран «Домой»), Android (Chrome → Установить приложение), Windows/Mac (значок установки в адресной строке) можно добавить Coffee Illy как отдельное приложение.
