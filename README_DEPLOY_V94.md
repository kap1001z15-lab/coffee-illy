# Coffee Illy v94.0 (Release 1.0.0) — Инструкция по обновлению

## Единый релиз
- **Release:** `1.0.0` · **Barista:** `94.0` · **Dashboard:** `94.0` · **API:** `1.0` · **Data schema:** `1.0`

## Что модернизировано в v94.0 (с сохранением всего функционала v93.0)
1. **Единая схема версий и проверка совместимости**: при несовпадении `API` или `Schema` между сервером и интерфейсом в дашборде показывается предупреждение.
2. **Усиленная безопасность и управление сессиями**:
   - Админ-сессия в `owner.html` больше не открывается по умолчанию без серверной проверки PIN (и не показывает PIN в тексте модалки).
   - Добавлена кнопка **«🚪 Завершить все активные сессии»** (мгновенно отзывает все токены сотрудников и администратора через `GLOBAL_SESSION_EPOCH`).
   - Поддержаны 4 роли сотрудников: `Бариста`, `Старший сотрудник`, `Администратор`, `Владелец`.
3. **Barista Simple (`index.html`) — 4 чистых раздела**:
   - **«Мой день»** (главный экран): статус смены (`🟢 На работе с ЧЧ:ММ`), прогресс чек-листов, приоритетный блок «Что сделать сейчас», статус кассового отчёта, открытые поломки и индикатор синхронизации/офлайн-очереди.
   - **«Чек-листы»**: пошаговое прохождение с камерой → Google Диск и защитой от дублей.
   - **Отдельный процесс «Кассовый отчёт»**: жизненный цикл `Черновик → На проверке → Подтверждён / Возвращён`, фото Z-отчёта на Google Диск, авторасчёт выручки и среднего чека, импорт POS CSV, защита подтверждённого отчёта от тихого редактирования, автоматическое создание инцидента при расхождении и уведомление в Telegram.
   - **«Информация»**: поиск по ТТК ILLY, актуальные объявления, список открытых поломок.
   - **«Профиль»**: данные сотрудника, статус очереди синхронизации, версия релиза, смена PIN и выход со смены.
4. **Owner Dashboard (`owner.html`) — 5 чистых разделов + умные счётчики (скрываются при 0)**:
   - **«Главная»**: KPI с пояснением формул (`Чистая прибыль = Выручка − Расходы`), переходы по клику к исходным разделам, статус склада и команда на смене.
   - **«Финансы»**: проверка кассовых отчётов (кнопки **«✓ Подтвердить»** / **«↩ Вернуть»** с личным уведомлением бариста в Telegram), ссылки на фото Z-отчётов, расходы, импорт CSV и **«⬇ Экспорт CSV»**.
   - **«Продажи»**: динамика за 14 смен, средний чек, недельный план и график смен.
   - **«Товары и склад»**: учёт остатков с минимальными запасами (автоматический Telegram-алерт администратору при падении ниже минимума) + ТТК ILLY.
   - **«Управление»**: чек-листы и окна, поломки, команда (4 роли), настройки точки + Telegram-бот (5-минутный автопилот) + отзыв всех сессий + журнал аудита.

2. **GitHub Pages**: распакуйте `coffee-illy-v94.0-release-1.0.0.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release 1.0.0 (v94.0): unified architecture, cash review, inventory alerts, 4/5-tab UI"

   ```
