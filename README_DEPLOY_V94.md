# Coffee Illy v94.0 (Premium Minimal + Material Design 3)

## Что изменено по спецификации аудита
- **Единая дизайн-система (`css/coffee-illy-v94.css`)**: светлая (тёплый молочный `#F7F4EF`, белые карточки, тёмный графит, кофейный акцент `#6F4E37`) и тёмная темы, кнопки 44–48 px, единые состояния загрузки, ошибок и пустых данных.
- **Убраны технические индикаторы**: больше нет `rev #`, `DATA_REV`, `--:--`. Вместо них — понятный статус синхронизации («Синхронизировано · ЧЧ:ММ», «Нет соединения — данные сохраняются на устройстве», «Ошибка загрузки · Повторить»).
- **Barista Simple (`index.html` + алиасы)**:
  - Нижняя 5-раздельная навигация: **Главная**, **Задачи**, **Касса**, **Поломки**, **ТТК**; профиль, смена PIN, тема и выход со смены вынесены в аватар в шапке.
  - **Главная**: смена, задачи на сегодня, прогресс чек-листов, 4 быстрых действия без дублей, последние уведомления.
  - **Задачи**: разделение на этапы (Открытие / В течение дня / Закрытие), автосохранение отметок, реальная камера → Google Диск, запрет незаметного редактирования после отправки.
  - **Касса**: пошаговая 4-шаговая форма (Счётчики → Денежные операции → Подтверждение и фото → Итоговый просмотр), защита от повторной отправки, статусы «На проверке» / «Подтверждён» / «Нужно исправить» с причиной возврата.
  - **Поломки**: 5-шаговая форма + 5 статусов (Новая / Принята / В работе / Ожидает запчасть / Решена) + мгновенный Telegram-алерт администратору.
  - **ТТК**: поиск, категории, объём, состав, время приготовления, аллергены, дата обновления.
- **Owner Dashboard (`owner.html` / `dashboard.html` + алиасы)**:
  - 9 разделов: **Обзор**, **Финансы**, **Продажи**, **Товары и склад**, **Чек-листы**, **Поломки и задачи**, **Команда и смены**, **Технологические карты**, **Настройки**.
  - Серверные финансовые расчёты (`financeSummary`), проверка и возврат кассовых отчётов, экспорт CSV, склад с историей движений (`inventory_move`), создание задачи из поломки в 1 клик, Telegram-бот и 5-минутный авто-триггер, резервное копирование.
- **Быстрая синхронизация между устройствами (`js/cloud-sync-v94.js`)**:
  - Активный пуллинг каждые **800 мс** (~0.8–1.5 сек между отдельными устройствами), `BroadcastChannel` (<50 мс в одном браузере), офлайн-очередь с защитой от дубликатов (`operationId`).

1. **Google Apps Script**: замените код на содержимое `Coffee_Illy_Code_v94.0.gs.txt` → Сохранить → **Развернуть → Управление развёртываниями → Редактировать → Новая версия → Развернуть**.
2. **GitHub Pages**: распакуйте `coffee-illy-v94.0-premium-minimal.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v94.0: Premium Minimal M3 redesign, server finance, warehouse, fast sync"
   git push origin main
   ```

## Откат к предыдущей версии
- В Git: `git revert HEAD && git push origin main` (или `git checkout <предыдущий_коммит>`).
- В Google Apps Script: **Развернуть → Управление развёртываниями → Редактировать → выберите предыдущую версию → Развернуть**.
