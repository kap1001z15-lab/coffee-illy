# Coffee Illy v94.0 (Full Production) — Инструкция по установке

## Все доработанные нюансы в v94.0
- **Авто-вход сотрудника + приветствие + отметка «На работе»**: автоматическое определение по Telegram ID (или запомненному устройству), запись на лист `Посещаемость`, живой бейдж `🟢 На работе · ЧЧ:ММ` в терминале и дашборде.
- **Черновики чек-листа и защита фото**: сделанные фото и текущий шаг сохраняются в локальном черновике (обновление страницы не сбрасывает прогресс), а кнопка завершения блокирует отправку, пока фото ещё загружается на Google Диск.
- **Только живые данные без старого кэша**: из `index.html` и `owner.html` убрана устаревшая история, добавлен авто-таймер реального времени (каждые 30 сек окна чек-листов открываются и закрываются сами) и индикатор офлайн-очереди (`⚡ Офлайн` / `☁ Очередь: N`).
- **Полная двусторонняя запись всех действий в Google Таблицу**: чек-листы с фото на Google Диск, касса, расходы, поломки, принудительное открытие и возврат штатного окна блока (`clear: true`), добавление и удаление задач, график смен (`Пн–Вс`), склад/остатки, сотрудники, ТТК и смена PIN владельца прямо из настроек.
- **Telegram-бот без хардкода**: мгновенный алерт администратору при любой поломке со ссылкой на фото на Google Диске и кнопкой перехода в `owner.html`, 5-минутный авто-триггер персональных уведомлений сотруднику при открытии чек-листа с кнопкой `▶️ Пройти «Название»` (`index.html?block=...`), а также динамический контроль просрочки по всем актуальным блокам из листа `Таймлайн`.

## Установка за 3 шага
1. **Google Apps Script**: скопируйте весь код из `Coffee_Illy_Code_v94.0.gs.txt` в ваш проект Apps Script → сохраните → **Развернуть → Управление развёртываниями → Редактировать → Новая версия → Развернуть**.
2. **GitHub Pages**: распакуйте `coffee-illy-v94.0-m3soft-full.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v94.0 full production"
   git push origin main
   ```
3. **Настройка Telegram-бота (1 раз)**: откройте `owner.html` → **Настройки и Безопасность** → укажите токен бота, Chat ID администратора и URL сайта → нажмите **«💾 Сохранить Telegram»**, **«🔔 Включить авто-уведомления (каждые 5 мин)»** и **«📨 Тест админу»**.
