# План тестирования и критерии приёмки (`TEST_PLAN.md`)

**Актуальный статус релиза:** `v75`  
**Состав автотестов репозитория:** 8 тестовых наборов в директории `tests/` (более 55 автоматизированных проверок).

## 1. Команда полного регрессионного прогона

Все тесты запускаются локально в Node.js без необходимости внешних сервисов:

```bash
for f in tests/*test*.js; do echo "=== $f ==="; node "$f"; done
```

Релиз допускается к публикации только при коде возврата `0` по каждому из 8 тестовых файлов.

## 4. Чек-лист ручной и визуальной приёмки перед запуском

1. **Терминал бариста (`index.html` на экране смартфона `390×844`):**
   - В шапке отображаются название точки, выбор сотрудника, статус подключения и кнопка выхода.
   - На главном экране виден блок **«Моя смена»** с текущим этапом, процентом выполнения и рабочей кнопкой «Продолжить».
   - Нижняя навигация из 4 кнопок (`Смена`, `Касса`, `Знания`, `Проблемы`) переключает разделы без прокрутки шапки.
   - В задаче поля описания поломки скрыты по умолчанию и появляются только после нажатия «⚠️ Обнаружена проблема».
   - В разделе «Касса» переключение между «Сдать смену» и «Расширенная касса» работает мгновенно, а отправка сохраняет запись в таблицу.
2. **Панель владельца (`owner.html` на ПК и планшете):**
   - Доступны все 7 разделов навигации (`Обзор`, `Операции`, `Финансы`, `Персонал`, `Стандарты`, `Контроль`, `Настройки`).
   - В разделе «Обзор» отображаются 4 главные карточки (Выручка, Расходы, Прибыль, Средний чек), состояние смены, финансовая динамика и лента последних событий.
   - В разделе «Финансы -> Сверка» при корректировке кассы сохраняются исходное значение бариста, скорректированная сумма, автор и время изменения.
   - В разделе «Персонал» открывается карточка/профиль сотрудника с историей его смен, отчётов и чек-листов.
   - В разделе «Стандарты» при изменении техкарты сохраняется запись в истории версий ТТК.
