# ИНСТРУКЦИЯ ПО РАЗВЁРТЫВАНИЮ — Coffee Illy (v71)
Актуальная версия: v71

## 1. Обновление серверной части (Google Apps Script)
1. Откройте вашу Google Таблицу кофейни → меню **Расширения → Apps Script**.
2. Замените содержимое файла `Code.gs` кодом из приложенного файла `Code.gs` (`v71`).
3. При первом запуске выполните функцию `setup_initial_credentials` (или используйте кнопку выгрузки настроек из интерфейса), чтобы убедиться, что все 16 листов и системные свойства созданы.
4. Нажмите **Начать развёртывание → Управление развёртываниями → Изменить (✏️) → Новая версия → Развернуть** (доступ: *Все / Anyone*). URL веб-приложения при этом не меняется.

## 2. Обновление клиентской части (GitHub Pages / Хостинг)
1. Распакуйте архив `kofeinya-v71-coffee-illy-master.zip` в корень вашего репозитория GitHub Pages.
2. Убедитесь, что в файле `config.js` указан ваш `API_URL` развёртывания Google Apps Script.
3. Откройте приложение — благодаря `version.js` (`COFFEE_VERSION = 'v71'`) Service Worker автоматически очистит старый кэш на телефонах бариста и в Telegram Mini App.
