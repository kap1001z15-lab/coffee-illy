# ИНСТРУКЦИЯ ПО РАЗВЁРТЫВАНИЮ И МИГРАЦИИ — Coffee Illy (v85)
Актуальная версия: v85

## Важно: синхронное обновление сервера и клиента
В релизе `v85` удалены заводские PIN-коды и добавлены новые коды ответов сервера (`SETUP_REQUIRED`, `PIN_CHANGE_REQUIRED`). **Обновляйте `Code.gs` и клиентские файлы одновременно.**

## Шаг 1. Обновление серверной части (Google Apps Script)
1. Откройте вашу Google Таблицу кофейни → меню **Расширения → Apps Script**.
2. Замените содержимое файла `Code.gs` кодом из приложенного файла `Code.gs` (`v85`) и сохраните проект (`Ctrl+S`).
3. **Для существующей рабочей таблицы**: выберите на верхней панели редактора Apps Script функцию **`migrateFactoryPins_`** и нажмите **«▶ Выполнить»**.
   - Функция заменит открытые PIN-коды в листах «Настройки» и «Сотрудники» на маску `••` и выставит сотрудникам без индивидуального хеша флаг `PIN_CHANGE_REQUIRED_<имя>=1`, чтобы при следующем входе они задали свой личный PIN.
4. **При случайной блокировке входа (5 неверных попыток)**: выберите функцию **`resetRateLimits_`** в редакторе Apps Script и нажмите **«▶ Выполнить»**.
5. Нажмите **Начать развёртывание → Управление развёртываниями → Изменить (✏️) → Новая версия → Развернуть** (доступ: *Все / Anyone*).

## Шаг 2. Обновление клиентской части (GitHub Pages / Хостинг)
1. Распакуйте архив `kofeinya-v85-coffee-illy-release.zip` в корень вашего репозитория GitHub Pages.
2. Убедитесь, что в файле `config.js` указан ваш `API_URL` развёртывания Google Apps Script.
3. При первом открытии Панели владельца (`owner.html`), если `ADMIN_PIN_HASH` ещё не задан, откроется экран **«Задайте PIN владельца»** (не менее 6 цифр).

## Шаг 3. Проверка после выкладки и план отката (Rollback)
1. Перед обновлением сделайте резервную копию (экспорт) рабочей Google Таблицы (**Файл → Создать копию**) или JSON-слепок в разделе «Управление → Настройки».
2. Порядок выкладки: **Экспорт таблицы → Новая версия Apps Script (`Code.gs v85`) → Обновление сайта (`v85`) → Запуск `migrateFactoryPins_()` → Проверка входа владельца и одного сотрудника**.
3. **Откат при необходимости**: в Google Apps Script выберите **Управление развёртываниями → Изменить → переключить на предыдущую версию развёртывания**, а в Git-репозитории выполните `git checkout v84-before-fixes`.
