# Дизайн-система Coffee Illy Premium (`DESIGN_SYSTEM.md`)

**Актуальный статус релиза:** `v67`  
**Назначение:** Единые правила визуального оформления, цветовых токенов, типографики, карточек, кнопок, состояний операций и адаптивной сетки для обоих интерфейсов (`Barista Simple` и `Owner Combined`).

## 1. Цветовая палитра (`Premium Light` и `Premium Dark`)

Основная тема системы — **Premium Light**. Цвет никогда не используется как единственный индикатор статуса: каждое состояние обязательно сопровождается текстовой меткой и иконкой.

### 1.1. Базовые токены (`Premium Light` — тема по умолчанию)

| Название токена | CSS-переменная | HEX-код | Назначение в интерфейсе |
| :--- | :--- | :---: | :--- |
| **Warm Ivory** | `--bg` | `#F7F5F0` | Основной фон страниц терминала и панели владельца |
| **Pure White** | `--surface`, `--cream` | `#FFFFFF` | Поверхность карточек, модальных окон, таблиц и рабочих областей |
| **Espresso** | `--ink`, `--espresso` | `#262522` | Основной высококонтрастный текст и заголовки (WCAG AAA) |
| **Coffee Brown** | `--brew`, `--accent` | `#795548` | Фирменный кофейный акцент, кнопки `Primary`, активные вкладки и прогресс |
| **Stone Gray** | `--muted` | `#85817A` | Вторичный текст, подписи, метки времени и неактивные состояния |
| **Success** | `--good` | `#398568` | Спокойный зелёный — подтверждённые операции, выполненные задачи, норма |
| **Warning** | `--warn` | `#D69A43` | Янтарный — ожидание отправки, предупреждения, приближение дедлайна |
| **Error** | `--bad` | `#C65C50` | Тёплый красный — ошибки, критические поломки, расхождения в кассе |
| **Warm Border** | `--line` | `#E6E1D8` | Тонкие деликатные границы карточек, полей ввода и разделителей |
| **Soft Chip** | `--chip` | `#EFECE4` | Подложка вторичных тегов, фильтров и переключателей |

### 1.2. Дополнительная тема (`Premium Dark`)

Реализована на той же геометрической сетке (`:root[data-theme="dark"]`):
- `--bg: #141413` · `--surface: #1E1D1B` · `--ink: #F5F3EE` · `--muted: #9E9A91` · `--line: #2E2C28`
- `--brew: #A67C68` · `--good: #4CA382` · `--warn: #E0A852` · `--bad: #D96B5F`

## 2. Типографика и числовое форматирование

Основной шрифт интерфейса — **`Inter`** (`'Inter', system-ui, -apple-system, 'Segoe UI', Roboto, sans-serif`).

| Элемент интерфейса | Размер шрифта | Начертание (`font-weight`) | Особенности |
| :--- | :---: | :---: | :--- |
| **Главный заголовок экрана** | `28–32 px` | `700–800` | Межбуквенный интервал `-0.02em`, высота строки `1.18` |
| **Заголовок раздела (`h2`)** | `22–26 px` | `700` | Межбуквенный интервал `-0.015em`, высота строки `1.25` |
| **Заголовок карточки (`h3`)** | `16–18 px` | `600–700` | Чёткая иерархия над основным текстом карточки |
| **Основной рабочий текст** | `14–16 px` | `400–500` | Высота строки `1.5`, комфортное чтение с экрана телефона |
| **Подписи и вторичные метки** | `12–13 px` | `500–600` | Цвет `--muted` (`#85817A`) |
| **Финансовые показатели** | `26–34 px` | `700–800` | Обязательно `font-variant-numeric: tabular-nums` (табличные цифры без скачков ширины при обновлении) |

## 3. Карточки, кнопки и компоненты

### 3.1. Геометрия карточек (`.panel`, `.card`)

- **Радиус скругления:** `14 px` (в диапазоне стандарта `12–16 px`).
- **Границы и тени:** тонкая рамка `1px solid var(--line)` (`#E6E1D8`) и мягкая рассеянная тень `0 2px 6px rgba(38, 37, 34, 0.04), 0 10px 24px -14px rgba(38, 37, 34, 0.08)` без тяжёлых тёмных обводок и декоративных градиентов.
- **Внутренние отступы:** `16–20 px` с достаточным свободным пространством между блоками (`12–16 px`).

### 3.2. Четыре типа кнопок

1. **Primary (`.btn`, `button.p`):** заливка `var(--brew)` (`#795548`), текст `#FFFFFF`, скругление `12–14 px`, высота нажатия на телефоне `48–54 px`. Используется для главного целевого действия экрана («Продолжить», «Далее», «Отправить счётчик и фото», «Сохранить»).
2. **Secondary (`.btn.ghost`, `button.b`):** светлая поверхность `#FFFFFF` или `var(--chip)` с тонкой границей `1px solid var(--line)` и текстом `#262522`.
3. **Tertiary (`.btn-text`):** текстовая кнопка без рамки для вспомогательных переходов («Показать фотообразец», «Сбросить»).
4. **Danger (`button.del`, `.btn.danger`):** акцентный стиль `var(--bad)` (`#C65C50`) для критичных и удаляющих действий («Удалить», «Сообщить о поломке руководителю»).

## 4. Единая матрица статусов задач и синхронизации

В системе запрещено показывать статус «Готово», если данные ещё не подтверждены сервером.

| Статус операции / задачи | Визуальный токен | Бейдж и текст в интерфейсе |
| :--- | :---: | :--- |
| **Не начато** | `#85817A` (Stone Gray) | `⚪ Не начато` |
| **В процессе** | `#795548` (Coffee Brown) | `🟤 В процессе` |
| **Сохранено на устройстве** | `#D69A43` (Warning) | `💾 Сохранено на устройстве · ожидает отправки` |
| **Ожидает отправки** | `#D69A43` (Warning) | `⏳ В очереди синхронизации (N)` |
| **Выполнено (подтверждено)** | `#398568` (Success) | `✓ Выполнено · подтверждено сервером` |
| **Есть проблема / Ошибка** | `#C65C50` (Error) | `⚠️ Обнаружена проблема` / `🔴 Ошибка отправки · повторить` |

## 5. Правила адаптивности

| Тип устройства | Терминал бариста (`Barista Simple`) | Панель владельца (`Owner Combined`) |
| :--- | :--- | :--- |
| **Смартфон (`< 640 px`)** | Основное устройство: фиксированная нижняя навигация на 4 раздела, крупные кнопки (`>= 48 px`), пошаговые формы | Быстрый просмотр сводных карточек «Обзор», центра уведомлений и экстренная разблокировка чек-листов |
| **Планшет (`640–1024 px`)** | Полноценная работа на барной стойке (2-колоночные карточки кассы и ТТК) | Полноценное управление всеми 7 разделами, проверка фотоотчётов и сверка кассы |
| **Компьютер (`> 1024 px`)** | Дополнительный режим проверки и обучения | Основное рабочее место: 7-раздельная навигация, широкие таблицы сверки, финансовая динамика P&L и мультиколоночные панели |
