# Coffee Illy v94.0 — Паспорт архитектуры, аудит и руководство по развёртыванию

## 1. Единая архитектура («One system. Two interfaces. One source of truth»)
- **Barista Simple (`index.html`, `barista.html`, `barista_terminal.html`)**: 4 раздела — **Мой день** (приветствие, статус смены, следующее действие без прокрутки, уведомления и статусы отчётов), **Чек-листы** (пошаговое прохождение с камерой на Google Диск + 4-шаговая **Сдача кассы**), **Информация** (ТТК только чтение, Объявления с подтверждением прочтения, Поломки с фото), **Профиль** (статус смены, Telegram ID, смена PIN, выход).
- **Owner Dashboard (`owner.html`, `admin.html`, `dashboard.html`, `owner_admin_app.html`)**: 5 разделов — **Главная** (живые KPI с формулой операционной прибыли `Выручка − Расходы`, график по планам дня недели, команда на смене, центр уведомлений), **Финансы** (кассовые отчёты с проверкой `Подтвердить / На уточнение / Отклонить`, расходы, планы дня), **Продажи** (нал/безнал, средний чек, смены, хиты — суммы отделены от количества), **Товары и склад** (ТТК + остатки склада с низкими порогами), **Управление** (чек-листы и окна, сотрудники с TG ID, поломки с фото Drive, настройки Telegram-бота + 5-мин триггер + аудит).
- **Единый Backend (`Code.gs`, Google Apps Script)** + **Google Таблица `Coffee_illy`** + **Google Диск (`Coffee_ERP_Photos`)**.

| Склад и остатки | Новое (v94.0) | Вкладка «Товары и склад» → пополнение/списание и контроль минимального остатка |

## 3. Обновление (3 шага)
1. **Google Apps Script**: замените код в Apps Script файлом `Coffee_Illy_Code_v94.0.gs.txt`, сохраните и нажмите **Развернуть → Управление развёртываниями → Редактировать → Новая версия → Развернуть**.
2. **GitHub Pages**: распакуйте `coffee-illy-v94.0-m3soft-production.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v94.0: full spec modernization (Barista Simple 4 tabs, Owner 5 tabs, cash review, notifications, warehouse)"
   git push origin main
   ```
3. **Проверка после запуска**: откройте `owner.html` → **Управление → Настройки, Telegram и аудит**, убедитесь, что токен, `Chat ID` и URL сайта сохранены, и при необходимости нажмите **«🔔 Включить авто-уведомления (каждые 5 мин)»**.
