# BUSINESS RULES — Свод бизнес-правил Coffee Illy (Этап 2)
Актуальная версия: v71

## 1. Правило единого источника истины для справочников
- Сотрудник создаётся или редактируется только в одном месте (`Персонал` -> `save_staff`).
- Система через `window.coffeeSyncStaffDirectory(db)` автоматически обновляет список сотрудников в селекторе входа терминала, графике смен, кассе, списках ответственных за задачи и инциденты, списке адресатов объявлений и финансовых отчётах ФОТ.

## 2. Правила кассы, счётчиков и списаний (неизменяемые)
- **Формула дельты трёхразрядного счётчика кофемашины (`0–999`)**:
  - Если `counterEnd >= counterStart`, то `grinderShots = counterEnd - counterStart`.
  - Если `counterEnd < counterStart` (переход через `999 -> 0`), то `grinderShots = (1000 - counterStart) + counterEnd` (например, `998 -> 2 = 4`, `999 -> 0 = 1`).
- **Формула сверки помолов кофемолки с продажами по CSV**:
  - `accountedShots = soldCoffee + writeoffShots`
  - `unaccountedShots = max(0, grinderShots - accountedShots)`
  - `overAccountedShots = max(0, accountedShots - grinderShots)`
- **Защита первоисточника кассы**:
  - Первичный отчёт бариста (`submit_cash`) никогда не перезаписывается без следа. Любая сверка или корректировка администратором (`admin_cash`) сохраняет исходную сумму `origTotal`, новую сумму `newTotal`, сумму Z-отчёта `zTotal`, расхождение `diff`, автора и причину в `cashHistory`.
- **Честная модель P&L (без фиктивных коэффициентов)**:
  - Себестоимость (`COGS`) рассчитывается строго по техкартам (`ТТК`) фактически проданных позиций (`costBeans + costMilk + costSyrup + costCup`).
  - Если постоянные расходы `OpEx` за период ещё не внесены, система не подменяет их фиктивным процентом, а явно маркирует прибыль как **операционный результат смены** с предупреждением о неполноте данных OpEx.
