# Coffee Illy v95.0 (M3 Soft Production) — Полный ERP-дашборд, авто-склад, все ТТК из отчётов и синхронизация

## Что входит в релиз v95.0
1. **Точная структура из 8 разделов** (`owner.html`):
   - **Обзор**: расширенные KPI, график выручки vs план дня, **сверка POS-отчётов (CSV) vs ручной ввод**, алерт заканчивающихся позиций склада, команда на смене.
   - **Продажи**: детальная разбивка по каждой проданной позиции — количество (шт.), выручка (₽), % от всех продаж, средняя цена за всё время, поиск и фильтр по категориям.
   - **Финансы**: подробная аналитика, **индивидуальные планы по дням недели (Пн–Вс: выручка, чеки, мин. средний чек и смена — кто выходит)**, расходы по категориям, импорт выписок POS CSV с автоматическим всплывающим окном и пометкой `CSV` / `Вручную`, генератор отчётов за период (CSV, Печать/PDF, Telegram).
   - **Склад**: **предзаполнен 24 базовыми позициями кофейни** (зерно ILLY, молоко 3.2%, альтернативное и безлактозное молоко, сливки, стаканчики 200/300/400 мл, крышки, трубочки, салфетки, сиропы, сахар, какао, маршмеллоу, чаи, основы, напитки, вода, лёд, химия) с синхронизацией в лист `Склад` Google Таблицы. Поддерживает ручное редактирование, `+ Приход`, `− Списать`, `✕ Удалить`, **автоматическое списание остатков по продажам** и **автоматические уведомления в Telegram**, когда позиция падает ниже минимума.
   - **Чек-листы**: полная настройка блоков и окон времени, мгновенное открытие/возврат окна, **полное индивидуальное редактирование каждой задачи** (название, инструкция, блок, ответственный, фото/видео, удаление/добавление) и **автоматическая сортировка истории прохождения от самых новых к самым старым** (на сервере и в интерфейсе).
   - **Поломки**: фильтры Открытые / Решённые / Все, решение поломок, встроенный просмотрщик фото и видео.
   - **Команда и ТТК**: сотрудники с показателями за период + **полная база техкарт из ваших POS-отчётов** с подробной пошаговой инструкцией приготовления, ценой продажи, средней ценой и **себестоимостью 0 ₽**, с поиском, фильтрами, редактированием, удалением и кнопкой массовой загрузки в Google Таблицу.
   - **Управление**: параметры точки, таблица сотрудников и графика смен, настройки Telegram-бота + автопилот каждые 5 минут, журнал аудита.
2. **Фильтры периода во всех разделах**: **Сегодня**, **Вчера**, **7 дней**, **30 дней**, **Всё время** и **Свой период** (выбор дат От–До).

## Установка (2 шага)
1. **Google Apps Script**: обновите `Code.gs` содержимым `Coffee_Illy_Code_v95.0.gs.txt`, сохраните и нажмите **Развернуть → Управление развёртываниями → Редактировать → Новая версия → Развернуть**.
2. **GitHub Pages**: распакуйте `coffee-illy-v95.0-m3soft-production.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v95.0: full warehouse auto-deduct, 47 report TTK, CSV vs manual comparison"
   git push origin main
   ```
3. **Первая синхронизация базы знаний**: откройте `owner.html` → **Команда и ТТК** → нажмите **«📥 Загрузить все из отчётов»** (запишет все ТТК в лист `ТТК`), а во вкладке **Склад** при необходимости нажмите **«📦 Базовый склад (24)»** (запишет склад в лист `Склад`).
