# Coffee Illy v95.0 (M3 Soft Production) — Развёрнутая статистика, сверка POS vs ручной ввод и База знаний

## Что нового в v95.0
1. **Обзор (`Обзор`)**:
   - Карточка автоматической сверки **«Отчёты POS vs Вписано вручную»** за выбранный период (сколько дней сошлось, где есть расхождения в ₽, сравнение сумм и чеков).
   - Визуальная полоса структуры оплат (**Наличные %** vs **Безнал / Мобильный платёж %**), рентабельность (%) и счётчики загруженных транзакций, позиций продаж и чек-листов.
2. **Продажи (`Продажи`)**:
   - **Категории продаж**: визуальные полосы с выручкой, количеством (шт.) и долей (%).
   - **Пиковые часы продаж (07:00–22:00)**: автоматический почасовой график по загруженным чекам POS с выделением часа пик.
   - **Рейтинг бариста по продажам**: смены, выручка, % выполнения плана, чеки, средний чек и разбивка Нал/Безнал.
   - **Топ продаж по номенклатуре** с поиском, фильтром категорий и журналом продаж по дням.
3. **Финансы и Сверка (`Финансы`)**:
   - **Подробная таблица сверки «Отчёты POS (CSV) vs Вписано вручную»** по каждой дате с фильтрами (`Все` / `⚠️ Расхождения` / `🔀 Оба источника`), отображением источника (`🔀 POS + Ручной`, `📥 POS CSV`, `✍️ Вручную`), суммой из POS-отчёта, суммой вписанной вручную, разницей `Δ ₽` и сверкой с листом `Продажи`.
   - **Структура расходов по категориям** с визуальными полосами и долей от выручки.
4. **База знаний и Google Таблица (`База знаний`)**:
   - Прямая кнопка **`↗ Открыть Google Таблицу`** и **живая сетка всех 12 листов** (`Касса`, `Продажи`, `Транзакции`, `Чек-листы`, `Задачи`, `Поломки`, `Расходы`, `ТТК`, `Сотрудники`, `Посещаемость`, `Медиафайлы`, `Аудит`) с актуальным количеством строк.
   - Интерактивный каталог **ТТК ILLY** с расчётом себестоимости, прибыли с чашки (+₽), маржи (%) и рецептуры + сводка стандартов чек-листов с быстрым переходом к редактированию.
