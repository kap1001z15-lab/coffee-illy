# Coffee Illy v95.0 (M3 Soft Production) — Полная 8-вкладочная структура дашборда и 50 ТТК из отчётов

## Структура дашборда (`owner.html`)
Точно как на скриншоте: **Обзор · Продажи · Финансы · Склад · Чек-листы · Поломки · Команда и ТТК · Управление**, с глобальным фильтром периодов (**Сегодня · Вчера · 7 дней · 30 дней · Всё время · Свой период**).

- **Обзор**: KPI за период, динамика выручки, сотрудники на смене сейчас (`🟢 На работе с ЧЧ:ММ`).
- **Продажи**: детализация по каждой позиции — количество (шт.), выручка (₽), доля от всех продаж (%), средняя цена за всё время.
- **Финансы**: базовые планы кофейни (выручка, чеки, мин. ср. чек, норма списаний), индивидуальные планы по дням Пн–Вс + график смен (кто выходит), расходы по категориям (включая «Стаканчики и расходники»), импорт POS CSV с автоматическим окном проверки и генератор отчётов (`📊 Сформировать отчёт`).
- **Склад**: стаканчики 180/250/350 мл, крышки, трубочки, салфетки, молоко 3.2%, альтернативное и безлактозное молоко, сливки, лёд, зерно ILLY, какао, сиропы, сахар — с приходом, списанием, редактированием, удалением и контролем мин. остатков.
- **Чек-листы**: полная настройка блоков (название, время открытия и дедлайна, принудительное открытие/возврат окна, добавление и удаление блока) и индивидуальное редактирование/удаление каждой задачи с подробной инструкцией.
- **Поломки**: 4 фильтра (**Открытые · Нерешённые · Решённые · Все**), смена статуса, добавление, удаление и просмотр фото/видео.
- **Команда и ТТК**: все **50 напитков и позиций из ваших отчётов** занесены в ТТК с подробной пошаговой инструкцией, средней ценой и ценой продажи из отчётов, **себестоимость = 0 ₽**, поиск/фильтр, просмотр рецепта, редактирование, удаление и кнопка **«☁️ В Google Таблицу (50)»** для сохранения одним кликом.
- **Управление**: сотрудники на смену (роли, графики, Telegram ID, PIN, добавление/редактирование/удаление), параметры точки и безопасности, Telegram-бот и авто-уведомления (каждые 5 мин), журнал аудита.

## Установка (2 шага)
1. **Google Apps Script**: обновите `Code.gs` содержимым `Coffee_Illy_Code_v95.0.gs.txt`, сохраните и нажмите **Развернуть → Управление развёртываниями → Редактировать → Новая версия → Развернуть**.
2. **GitHub Pages**: распакуйте `coffee-illy-v95.0-m3soft-production.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v95.0: 8-tab dashboard, 50 report TTK (cost=0), warehouse, full CRUD"
   git push origin main
   ```
3. Откройте `owner.html` → **Команда и ТТК** и нажмите **«☁️ В Google Таблицу (50)»**, чтобы записать все 50 техкарт в лист `Техкарты`.
