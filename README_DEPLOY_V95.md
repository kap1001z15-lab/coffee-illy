# Coffee Illy v95.0 (M3 Soft Production) — Полная аналитика, сверка POS vs Вручную, База знаний и Google Таблица

## Что нового в v95.0
1. **Обзор (Overview)**:
   - Блок **«Сверка: Отчёты POS vs Вручную»** с наглядными полосами сравнения, количеством совпавших дней, расхождений и суммарной разницей.
   - Блок **«Google Таблица · База данных»** с прямой ссылкой на таблицу `Coffee_illy`, живыми счётчиками строк по всем 11 листам (`Касса`, `Продажи`, `Транзакции`, `Расходы`, `Чек-листы`, `Поломки`, `Задачи`, `Сотрудники`, `ТТК`, `Посещаемость`, `Аудит`), временем синхронизации и пингом.
2. **Продажи (Sales)**:
   - **Почасовая активность продаж** (график по часам дня с выделением пикового часа на основе загруженных CSV `Транзакции`).
   - **Структура оплат** (визуальная полоса Наличные vs Безнал/Мобильный платёж в ₽ и %).
   - **Топ-10 позиций** с прогресс-барами доли выручки и автоматическим расчётом маржинальности из ТТК.
3. **Финансы (Finances)**:
   - **Таблица сверки по каждому дню**: `📄 POS-отчёт` vs `✍️ Вручную / Касса`, разница в ₽, чеки, кофе (шт.) и статус (`✓ Совпадает`, `±X ₽`, `📄 Только POS`, `✍️ Только вручную`).
   - Кнопка **«+ Вписать кассу вручную»** прямо в дашборде владельца + автоматическое всплывающее окно при загрузке CSV-выписок.
   - **Расходы по категориям** с визуальными долями (%) и сводный отчёт за период (CSV, печать/PDF, Telegram).
4. **База знаний, ТТК и Стандарты (`Команда и ТТК`)**:
   - KPI-панель Базы знаний (кол-во ТТК, средняя маржа %, лидер по марже, кол-во стандартов).
   - Фильтр категорий, живой поиск по рецептуре и стандартам, просмотр карточки ТТК (`👁`) и автоматический подсчёт реальных продаж по каждой ТТК из POS-выписок.
   - Полный справочник стандартов и инструкций смены по всем блокам чек-листов.

2. **GitHub Pages**: распакуйте `coffee-illy-v95.0-m3soft-production.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
