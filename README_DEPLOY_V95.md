# Coffee Illy v95.0 (M3 Soft Complete) — Полная сборка всех задач и рекомендаций

## Что включено в v95.0
1. **Google Pixel Material 3 Time Picker (`js/m3-controls-v95.js`)**: крупные цифровые плитки Часы : Минуты, круговой циферблат 24ч / 60м и быстрые пресеты при настройке окон чек-листов в дашборде (`owner.html`).
2. **Единые кастомные M3-списки (`M3Select`)**: авто-замена нативных браузерных `<select>` на всплывающее M3-меню на ПК и bottom-sheet на мобильных устройствах.
3. **Умная финансовая аналитика (`js/finance-analytics-v95.js`)**: 5 периодов (`Сегодня` / `Вчера` / `Неделя` / `Месяц` / `Всё время`), 4 KPI с дельтами к предыдущему периоду, автоматические выводы простым языком, график выручки, аккордеоны (структура расходов, эффективность бариста) и живой поиск по журналу смен.
4. **Кросс-ОС пробуждение синхронизации (`pageshow` bfcache)** в `js/cloud-sync-v95.js` — мгновенная синхронизация на iPhone/iPad Safari и Telegram Mini App после возврата из фона.
5. **Чистые векторные SVG-иконки** в нижней навигации терминала (`index.html`).
6. **Полный набор функций v93–v94**: авто-вход по Telegram ID + приветствие + отметка «На работе» (`Посещаемость`), всегда актуальный дашборд, мульти-фото и видео с камеры на Google Диск, мгновенные Telegram-алерты администратору об инцидентах, 5-мин уведомления сотрудникам о чек-листах с кнопкой, рассылка новых ТТК, POS CSV-импорт и складской учёт.

## Установка
1. **Google Apps Script**: обновите `Code.gs` из файла `Coffee_Illy_Code_v95.0.gs.txt` (если уже стоит v94.0, серверный код полностью совместим — достаточно переразвернуть новую версию).
2. **GitHub Pages**: распакуйте `coffee-illy-v95.0-m3soft-complete.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v95.0: M3 Pixel Time Picker, M3Select, Smart Finance Analytics, SVG nav, iOS pageshow sync"
   git push origin main
   ```
