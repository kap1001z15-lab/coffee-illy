# Coffee Illy v94.1 (M3 Soft Production) — Полная синхронизация, выписки кассы, задачи, отчёты и медиа

## Что исправлено и добавлено в v94.1
1. **Выписки кассы (POS CSV) и автоматическое всплывающее окно**:
   - Подключён парсер `js/pos-csv-parser-v93.js` в `index.html` и `owner.html` (ранее скрипт отсутствовал в HTML-тегах, поэтому кнопки загрузки CSV не обрабатывали файлы).
   - При выборе 1 или нескольких выписок (Транзакции + Продажи, включая файлы с «Номиенклатура», «Мобильный платеж», «Топал» → Алина, «Молокова» → Соня) **автоматически всплывает окно** с полной расшифровкой: выручка, нал/безнал, чеки, позиции, хиты продаж, предупреждения и кнопка **«✓ Сохранить выписку в Google Таблицу»** с защитой от дублей.
2. **Полное редактирование и удаление задач администратором + синхронизация Админ ↔ Бариста**:
   - В окне «Задачи» (`owner.html`) добавлена кнопка **✏️ Редактировать** (название, инструкция, блок, ответственный, обязательность фото/видео) и синхронизируемое удаление **✕**.
   - В `Code.gs` добавлен `bumpDataRev_()` во все мутации (`saveTask_`, `deleteTask_`, `saveTtk_`, `deleteTtk_`, `deleteStaff_`, `addExpense_`, `deleteExpense_`, `updateIncident_`) и поддержка возврата окна (`extendDeadline_` с `clear: true`).
   - В `js/cloud-sync-v94.js` добавлена защита от перезаписи локальных правок, пока очередь отправки не пуста, и полная отправка всех действий администратора и бариста.
3. **Удобное открытие фото и видео**:
   - Видео на Google Диске теперь сохраняется со ссылкой `/preview` вместо сырого `export=download`, а в `owner.html` встроен **лайтбокс-просмотрщик** (`📷` / `🎬`) для мгновенного открытия фото и проигрывания видео на iOS, Android, ПК и в Telegram Mini App.
4. **Сводные отчёты за период**:
   - В разделе **Финансы** добавлена кнопка **«📊 Сформировать отчёт»**: выручка vs план, нал/безнал, расходы, чистый итог, таблица по сотрудникам, чек-листы, инциденты, плюс кнопки **📥 Скачать CSV**, **🖨 Печать / PDF** и **📨 Сводку в Telegram**.

## Установка (2 шага)
1. **Google Apps Script**: обновите `Code.gs` содержимым `Coffee_Illy_Code_v94.1.gs.txt`, сохраните и нажмите **Развернуть → Управление развёртываниями → Редактировать → Новая версия → Развернуть**.
2. **GitHub Pages**: распакуйте `coffee-illy-v94.1-m3soft-production.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash
   cd /c/Users/COMP/Documents/GitHub/coffee-illy
   git add -A
   git commit -m "Release v94.1: CSV auto-modal, task CRUD sync, media lightbox, reports"
   git push origin main
   ```
