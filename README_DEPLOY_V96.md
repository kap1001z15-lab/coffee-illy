# Coffee Illy v96.0 (M3 Soft Production) — Полные 8 разделов из Google Таблицы + умные расчёты + кроссплатформенная синхронизация

## Что исправлено и доработано в v96.0
1. **Обзор**: живые KPI, график выручки vs план дня, точная сверка POS-отчётов (CSV) vs ручной ввод (определяет POS-дни как по `csvHashes`, так и по датам из листа `Продажи`), алерт заканчивающихся позиций склада, команда на смене из `Посещаемость` и живого кэша.
2. **Продажи (546+)**: исправлена классификация категорий `coffee` / `non_coffee` из листа `Продажи` Google Таблицы → корректная доля **Кофе / Не-кофе**, автоматическая разбивка на **Кофе**, **Десерты**, **Чай и напитки**, **Не-кофе**, а также исправлен поиск `#sales-q` (курсор и фокус больше не сбрасываются при вводе).
3. **Финансы (12+)**: кассовые смены с бейджами `CSV` / `Вручную`, автоматическое всплывающее окно при загрузке POS CSV выписок, расходы, индивидуальные планы Пн–Вс (выручка, чеки, мин. средний чек, смена) и генератор сводных отчётов (CSV, Печать/PDF, Telegram).
4. **Склад (24+ позиций вместо 1)**: исправлен порог автозаполнения в `Code.gs` и на клиенте — если на складе меньше 5 позиций, все 24 базовые позиции кофейни автоматически добавляются без удаления ваших существующих товаров. Если ручных движений или сроков годности ещё нет, автоматически рассчитывается расход по реальным продажам (`salesLog`) и открытые позиции бара в сроках годности.
5. **Чек-листы (30+)**: сортировка от новых к старым, полное редактирование/удаление задач с мгновенной синхронизацией в терминал бариста, встроенный лайтбокс для фото и видео.
6. **Поломки (24+)**: нормализация статусов (`Resolved` / `Решено` / `Закрыто` → `Решена`, пустой статус → `Новая проблема`), фильтры, решение поломок и встроенный просмотр фото/видео.
7. **Команда и ТТК**: сотрудники с живым статусом смены и KPI за период, карточки **Аудит сервиса** (из листа `Аудит сервиса`) и **Карта добрых дел** (из листа `Карта добрых дел`), автообогащённые **Техкарты (ТТК)** по всем позициям из `Техкарты` + `Продажи` (с поиском без потери фокуса).
8. **Управление**: реальный журнал аудита подтягивается напрямую из листа **`Журнал`** Google Таблицы (ранее искался отсутствующий лист `Аудит`), параметры точки, график смен, Telegram-бот и 5-минутный автопилот.
9. **Кроссплатформенность и быстрая синхронизация**: iOS/Android/Telegram safe-area и плавный тач-скролл, единый клиент `cloud-sync-v96.js` (опрос `get_rev` каждые 900 мс + `BroadcastChannel` + офлайн-очередь без потери правок).

2. **GitHub Pages**: распакуйте `coffee-illy-v96.0-m3soft-production.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов и выполните:
   ```bash

   git add -A

   ```
