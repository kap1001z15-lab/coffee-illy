# Coffee Illy v93.0 (M3 Soft Production) — Инструкция по обновлению

## Что нового в v93.0
1. **Автоматический вход по сотруднику + приветствие + отметка «На работе»**:
   - В Telegram Mini App сотрудник определяется автоматически по `Telegram ID` из листа `Сотрудники` (демо-список «Источник входа» удалён).
   - В обычном браузере после первого входа по PIN устройство запоминается и при следующих открытиях вход также выполняется автоматически.
   - При входе показывается приветствие, в шапке появляется бейдж `🟢 На работе · ЧЧ:ММ`, а в Google Таблице фиксируется запись на листе `Посещаемость` и живой статус смены для дашборда.
2. **Всегда актуальный дашборд владельца (`owner.html`)**:
   - Подтягивает свежие данные напрямую из Google Таблицы при открытии и каждые ~0.9–1.8 сек при активной работе, показывает время последнего обновления, пинг (мс) и список сотрудников, которые сейчас на смене.
3. **Мгновенные уведомления администратору в Telegram при инцидентах**:
   - При любой поломке (внеплановой или внутри чек-листа) бот сразу отправляет администратору сообщение с приоритетом, участком, именем бариста, ссылкой на фото на Google Диске и кнопкой перехода в дашборд.
4. **Автоматическое уведомление сотруднику при открытии чек-листа + кнопка перехода**:
   - Серверный триггер каждые 5 минут проверяет открывшиеся окна чек-листов и отправляет назначенному на смену сотруднику личное сообщение в Telegram с кнопкой `▶️ Пройти «Название»`, которая сразу открывает нужный чек-лист (`index.html?block=...`).

## Установка (2 шага)
1. **Обновите Google Apps Script (`Code.gs`)**:
   - Откройте ваш проект Apps Script, замените код на содержимое файла `Coffee_Illy_Code_v93.0.gs.txt`, сохраните.
   - Нажмите **Развернуть → Управление развёртываниями → Редактировать (карандаш) → Новая версия → Развернуть**.
2. **Обновите GitHub Pages**:
   - Распакуйте `coffee-illy-v93.0-m3soft-production.zip` в `C:\Users\COMP\Documents\GitHub\coffee-illy` с заменой файлов.
   - В Git Bash выполните:
     ```bash
     cd /c/Users/COMP/Documents/GitHub/coffee-illy
     git add -A
     git commit -m "Release v93.0: auto-login, on-shift presence, Telegram bot alerts"
     git push origin main
     ```
3. **Включите Telegram-бота и авто-уведомления**:
   - Откройте `owner.html` → **Настройки и Безопасность** → блок **Telegram-бот**.
   - Укажите **Токен бота** (от @BotFather), **Chat ID администратора** и **URL вашего сайта на GitHub Pages**.
   - Нажмите **💾 Сохранить Telegram**, затем **🔔 Включить авто-уведомления (каждые 5 мин)** и проверьте кнопкой **📨 Тест админу**.
